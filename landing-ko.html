모듈식 번역, 모든 것을 제어

11개의 내장 모듈. 자유롭게 조합하고 필요할 때 켜세요.

모듈식 아키텍처

모든 기능은 모듈입니다.선택 번역, 호버 번역, 선택즉번역, 번역 엔진, 텍스트 처리, 백그라운드 서비스 — 모두 모듈 시스템으로 통합 관리됩니다. 한 번의 클릭으로 ON/OFF, 필요에 따라 확장 가능합니다.

번개 같은 번역

조작 단계가 5단계에서 2단계로 줄고, 번역 속도는 75% 향상되어 0.5초 안에 결과가 나타납니다.

정밀 인식

DOM 직접 추출 기술로 OCR 단계를 생략하고 정확도 98%+를 달성하며, 다중 지점 샘플링으로 텍스트를 온전히 유지합니다.

AI 언어 감지

심층 문자 특징 분석으로 일본어, 한국어, 영어, 중국어 등 10+ 언어를 자동 인식합니다. 원문 언어를 직접 선택할 필요가 없습니다.

모듈 생태계

.qt-module로 번역 엔진, 상호작용 모드, UI 테마를 확장하세요. 커뮤니티 모듈은 가져오면 바로 사용할 수 있습니다.

호버 번역

Alt 키를 누른 채 마우스를 올리면 선택 없이 바로 번역되어 몰입형 읽기가 끊기지 않습니다.

단어장

자주 쓰는 번역을 저장하고 기록은 자동 보관. 500개 대용량으로 복습과 조회가 편합니다.

다크 모드

시스템 테마를 자동으로 따라가며 팝업, 패널, 스크린샷 화면까지 다크 모드에 최적화됩니다.

텍스트 정리

불필요한 공백, 줄바꿈, HTML 엔티티를 자동 정리하고 코드 블록은 손상되지 않도록 보호합니다.

번역 캐시

번역 결과를 스마트하게 캐시해 같은 내용은 다시 요청하지 않습니다. 최대 200개로 더 빠르고 데이터도 절약됩니다.

우클릭 번역

선택 후 우클릭만으로 번역되며 단일/다중 엔진 모드를 지원합니다. 결과 말풍선은 드래그와 저장이 가능합니다.

FAQ

자주 묻는 질문

문제가 있으신가요? 여기서 답을 찾으세요

chrome://extensions/shortcuts로 이동하여 단축키 설정을 확인하고 다른 확장 프로그램과 충돌하지 않는지 확인하세요. 새 단축키 조합을 수동으로 설정할 수도 있습니다.
선택한 영역에 선명한 텍스트가 포함되어 있는지 확인하세요. 이미지, 특수 폰트 또는 복잡한 배경의 텍스트는 정확하게 인식되지 않을 수 있습니다. 대비가 높은 텍스트 영역을 선택하세요.
현재 일본어, 한국어, 영어, 독일어, 프랑스어, 스페인어 등 10+ 언어를 중국어(간체/번체)로 번역할 수 있습니다. 원문 언어는 자동 감지되어 직접 선택할 필요가 없습니다.
확장 아이콘을 클릭해 메인 화면을 열면 제목 표시줄 오른쪽에 언어 선택기가 있습니다. 간체 중국어, 번체 중국어, 영어, 일본어, 한국어 5개 인터페이스 언어를 지원하며 설정은 자동 저장됩니다.
더 정확한 영역을 선택하거나 고급 설정에서 다른 번역 엔진으로 전환해 보세요. Google 번역은 일상용에 적합하고, GLM 대형 모델은 품질이 더 높지만 API 키가 필요합니다.
