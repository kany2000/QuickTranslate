モジュールを作成しましたか？コミュニティと共有しましょう！

📦 Issues で提出（簡単） 📖 両方の方法を学ぶ

📝 方法 A: GitHub Issues 簡単

  1. .qt-module ファイルを準備
  2. GitHub Releases またはサーバーにアップロード
  3. 新しい Issue を開きテンプレートを入力
  4. モジュール名、ID、タイプ、URL を記入
  5. 管理者が審査（1-3営業日）
  6. モジュールがストアに登場 ✨
📦 今すぐ提出

⚡ 方法 B: GitHub OAuth（自動PR） 上級

  1. 「GitHubでログイン」をクリックして承認
  2. .qt-module ファイルを直接アップロード
  3. システムが manifest を自動検証
  4. 自動でリポジトリをフォークしてPR作成
  5. 管理者が審査してマージ
  6. モジュールが公開 🚀
