모듈을 개발하셨나요? 커뮤니티와 공유하세요!

📦 Issues로 제출 (간편) 📖 두 방법 알아보기

📝 방법 A: GitHub Issues 간편

  1. .qt-module 파일 준비
  2. GitHub Releases 또는 서버에 업로드
  3. 새 Issue 열고 템플릿 작성
  4. 모듈 이름, ID, 유형, URL 입력
  5. 관리자 검토 (1-3 영업일)
  6. 모듈이 스토어에 등록 ✨
📦 지금 제출

⚡ 방법 B: GitHub OAuth (자동 PR) 고급

  1. 「GitHub 로그인」클릭하여 인증
  2. .qt-module 파일 직접 업로드
  3. 시스템이 manifest 자동 검증
  4. 자동으로 포크 및 PR 생성
  5. 관리자 검토 후 병합
  6. 모듈 출시 🚀
