Modular Translation, Fully in Control

11 built-in modules — combine freely, toggle on demand

Modular Architecture

Everything is a module.Selection translate, hover translate, select-to-translate, translation engines, text processors, background services — all managed by the module system. Toggle on/off with one click, extend as needed, no more switching between settings pages.

Lightning Translation

Steps cut from 5 to 2, translation 75% faster — results in under 0.5 seconds.

Precise Recognition

Direct DOM extraction skips OCR entirely, hitting 98%+ accuracy with multi-point sampling that keeps text intact.

AI Language Detection

Deep character-feature analysis auto-detects 10+ languages including Japanese, Korean, English and Chinese — no manual source selection.

Module Ecosystem

Extend translation engines, interaction modes and UI themes through .qt-module — community modules work the moment you import them.

Hover Translation

Hold Alt and hover — translate without selecting a thing, keeping immersive reading uninterrupted.

Word Book

Save the translations you use most, with automatic history — 500 entries of room for easy review.

Dark Mode

Follows your system theme automatically — popup, panels and screenshot UI all adapt to dark backgrounds.

Text Sanitizer

Strips redundant spaces, line breaks and HTML entities, while code blocks stay protected from damage.

Translation Cache

Smart caching skips duplicate requests for identical content — up to 200 entries, faster and lighter on data.

Context Menu

Select and right-click to translate, with single or multi-engine modes and draggable, savable result bubbles.

FAQ

Frequently Asked Questions

Have questions? Here are the answers

Go to chrome://extensions/shortcuts to check your keyboard shortcut settings. Make sure there are no conflicts with other extensions. You can also manually set a new shortcut combination.
Make sure the selected area contains clear text. Images, special fonts, or text with complex backgrounds may not be accurately recognized. We recommend selecting areas with high text contrast.
Currently 10+ languages — Japanese, Korean, English, German, French, Spanish and more — can be translated into Chinese (Simplified/Traditional). The source language is detected automatically, with no manual selection needed.
Click the extension icon to open the main UI — the language selector sits on the right of the title bar. Five interface languages are supported: Simplified Chinese, Traditional Chinese, English, Japanese and Korean. Settings are saved automatically.
Try selecting a more precise text area, or switch engines in Advanced Settings. Google suits everyday use, while GLM's large model delivers higher quality but requires an API key.
