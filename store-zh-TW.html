開發了模組？分享給社群，幫助 QuickTranslate 成長！

📦 透過 Issues 提交（簡單） 📖 了解兩種方式

📝 方法 A：GitHub Issues 簡單

  1. 準備好你的 .qt-module 檔案
  2. 上傳到 GitHub Releases 或你的伺服器
  3. 打開 Issue，填寫模板表單
  4. 填寫模組名稱、ID、類型、下載連結
  5. 管理員審核，1-3 個工作日內完成
  6. 你的模組出現在商店中 ✨
📦 立即提交

⚡ 方法 B：GitHub OAuth（自動 PR） 進階

  1. 點擊「登入 GitHub」授權
  2. 直接上傳 .qt-module 檔案
  3. 系統自動驗證 manifest 完整性
  4. 自動 Fork 倉庫並建立 PR
  5. 管理員審核後合併
  6. 你的模組上線 🚀
