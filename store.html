Submit Your Module

Built a module? Share it with the community and help QuickTranslate grow!

📦 Submit via Issues (Simple) 📖 Learn Both Methods

📝 Method A: GitHub Issues Easy

  1. Prepare your .qt-module file
  2. Upload to GitHub Releases or your server
  3. Open a new Issue with the template form
  4. Fill in module name, ID, type, download URL
  5. Admin reviews and merges within 1-3 days
  6. Your module appears in the Store ✨
📦 Submit Now

⚡ Method B: GitHub OAuth (Auto PR) Advanced

  1. Click "Login with GitHub" to authorize
  2. Upload your .qt-module file directly
  3. System auto-validates the manifest
  4. Auto-forks the repo and creates a PR
  5. Admin reviews and merges
  6. Your module goes live 🚀
